# JingBear Technical Data Audit

Date: 2026-10-08

## Publication rule

JingBear will use **individual model/family Technical Specification sheets** as the primary downloadable technical document. A separate **JingBear Equipment Guide** will act as a lead-magnet overview/catalog. It is not the technical authority for a specific purchase.

### Status levels
- **Ready** — sufficient documented data for a public technical sheet.
- **Preliminary** — public source exists, but model/configuration conflicts or gaps must remain explicit.
- **Not ready** — do not publish a technical PDF yet; keep the product visible but route buyers to configuration/RFQ.

## Publication architecture

1. Product image → Product Detail / family page.
2. Product Detail → Key specifications → Technical Specification download.
3. Technical Specification → WhatsApp/RFQ CTA.
4. Products hub → **JingBear Equipment Guide** as a separate overview download.

This avoids turning every technical file into a catalog while still giving buyers a downloadable overview when they are early in the buying cycle.
